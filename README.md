# Doctor's Appointment Booking System

## About the Project

A healthcare appointment booking system developed as part of a group university project.

The system was designed to manage patient appointments and provide functionality for booking, updating and cancelling appointments.

## Technologies Used

* C#
* ASP.NET / .NET
* Visual Studio
* SQL Server
* HTML
* Bootstrap

## Main Features

* User login
* Patient details management
* Appointment booking
* Appointment cancellation
* Payment functionality
* Patient and doctor information management
* Database integration

## Database

SQL Server was used to store and manage patient, doctor and appointment information.
